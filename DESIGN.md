# NearDrop interface

Native iOS conventions are the visual authority, following the requested AirDrop-like interaction. Mode: Operate. SwiftUI NavigationStack, grouped lists, semantic system colors, San Francisco text styles, SF Symbols, and system button/sheet behavior. One blue tint; support Dynamic Type, VoiceOver, Reduce Motion, and dark appearance.

The app opens on the paired computer or a focused pairing invitation. The share sheet names the receiver, automatically sends to the remembered PC, shows preparation and byte progress, then shows confirmed file counts with Done. Failure keeps a retry action and preserves successfully acknowledged transfers in the current session.

The PC's local browser control page emphasizes receiver availability, save location, pairing QR, paired phones, and recent files. It uses native system fonts, simple rows, restrained blue controls, and responsive light/dark surfaces. No upload webpage, cloud account, or imitation of the iOS share sheet.

Actual iOS screenshot verification requires Xcode Simulator or an iPhone and cannot be represented by web mockups.
